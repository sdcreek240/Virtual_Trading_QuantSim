## E01: Secure Identity & Access Management (✅ Complete)
Foundational epic for user management.
-   **Goal:** Secure user authentication and authorization via JWT.
-   **Features:** Registration, Login, Protected routes, Role-based access.

## E02: Live Market Data Feed (🚧 In-Progress)
Core system for streaming real-time prices.
-   **Goal:** Reliable delivery of latest asset prices to clients.
-   **Features:** Asset discovery, WebSocket price streams, Price history.

## E03: Real-Time Trading Engine (📋 Planned)
Heart of the simulator logic.
-   **Goal:** Instant execution of BUY/SELL orders with zero-latency feeling.
-   **Features:** Order placement, Validation, In-memory execution, Audit logging.

## E04: Interactive Trading Dashboard (UI) (🚧 In-Progress)
Primary user interface for the platform.
-   **Goal:** Modern, responsive dashboard with rich charts and feedback.
-   **Features:** Real-time charts, Trade forms, Dynamic layouts.

## E05: Portfolio & Performance Analytics (📋 Planned)
User value tracking and historical insights.
-   **Goal:** Visualizing gains/losses and asset distribution.
-   **Features:** ROI tracking, Holding summary, Performance charts.
